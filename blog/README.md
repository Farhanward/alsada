  Article JSON-LD schema + وصف/OG + محتوى GEO يذكر CarbonFlow + CTA (إيميل/جوال/الموقع).

## توليد/تحديث المقالات
```
python tools/blog_generate.py
```

## النشر الآلي (`tools/blog_publish.py` — مهمة «AlSada Blog Publisher» يومياً 09:05)
كل يوم ينشر المقالات المستحقّة (publishAt <= اليوم). **آمن:** لا ينشر ولا يُرسل IndexNow
إلا إذا وُجّه إلى مصدر الموقع الحيّ الحقيقي عبر متغيّري بيئة:
```
ALSADA_BLOG_PUBLIC_DIR = <مسار public/blog في مصدر الموقع الحيّ الحالي>
ALSADA_BLOG_DEPLOY_CMD  = <أمر البناء/النشر بعد النسخ، اختياري>
```
حتى تُضبط هذه، يكتفي بتسجيل «N مستحقّ — بانتظار المصدر» دون أي فعل تدميري.

## لماذا لم يُنشر تلقائياً بعد؟
نسخة الموقع المحلية `Desktop\CarbonFlowwebsite` **قديمة** (تنقصها مقالات وصفحات حيّة)،
والنشر منها يمسح محتوى الموقع الحيّ. توكن Cloudflare مقيّد (لا نشر/D1). لتفعيل النشر:
1. حدّد مسار **المصدر الحالي الحقيقي** للموقع (حيث تُبنى عمليات النشر)، أو
2. زوّدني بتوكن Cloudflare بصلاحية **Workers Scripts: Edit** (+ D1 عند اللزوم).
عندها أضبط `ALSADA_BLOG_PUBLIC_DIR` وتبدأ الحزمة بالنشر تلقائياً 3 مقالات أسبوعياً + IndexNow.
